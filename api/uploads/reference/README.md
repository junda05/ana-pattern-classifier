# Reference image gallery

The comparison view in the analysis screen shows reference images for each ANA pattern.
No images are shipped with the application; add images you are licensed to use.

Layout: one folder per pattern class, named exactly like the `PredictionClass` value, e.g.

    uploads/reference/NUCLEAR_HOMOGENEOUS/example-1.jpg
    uploads/reference/CYTOPLASMIC_RETICULAR_AMA/example-1.png

Accepted extensions: .jpg, .jpeg, .png, .bmp, .tiff. Folders with any other name are ignored.
